## Source and trust boundary

The producer is an independent local Git repository without an announced fetchable URL. The shared `import-source.sh` accepts one of the two package names, an explicit checkout, full commit, and independently recorded expected Git-archive BLAKE3. For an update it parses the prior receipt, requires that commit in the supplied checkout, re-archives it, verifies its recorded BLAKE3, and compares the complete extracted prior tree against the existing vendor paths, modes, symlinks, and file bytes. Missing prior identities, untracked files (even empty directories), and any drift fail before replacement; an identical pin is a no-op. On a verified change the importer stages the new archive and receipt, restoring the previous tree and receipt on a failed replacement. Archive digests cover tar bytes and are not Nix source hashes. Both complete snapshots live inside the onixpkgs revision; builds never read the local checkout. A new producer revision requires an explicit reviewed commit/digest pair and consumer adoption. No transport or remote is inferred.

## Package output

`rustPlatform.buildRustPackage` builds the library with `--lib` and exercises all crate targets with `cargoTestFlags = [ "--all-targets" ]`. Its default binary installation would be inappropriate for a library-only crate. An explicit install phase instead publishes Cargo.toml, Cargo.lock, src, and dual licenses as a source artifact to be compiled by a consumer's own Cargo graph. pkg-config and OpenSSL match the independent repository's flake dependencies. `pkgs.radicle-cob-git-store-020` receives the newer package through `callPackage` and overrides its `crateSource`, `crateLock`, and `crateVersion`, so the same function builds/tests both immutable cohort snapshots. A build demonstrates its own crate compiles and passes local tests with this Nix toolchain; it cannot prove downstream actor authority or host behavior.

`overlay.nix` already auto-registers each `pkgs/<name>/default.nix`. `flake.nix` restricts both exports to the producer's supported Linux systems. `treefmt.nix` excludes both imported snapshots to prevent accidental mutation. No flake input, sibling path, runtime service, or consumer policy is added.
